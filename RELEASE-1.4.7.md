# MGM Agent Admin 1.4.7

Windows x64 · November 18, 2026

This release integrates the response and cost correction identified by engine revision `response-cost-2026-11-18.3`. It groups history writes, reads independent server state in parallel, shortens initial greetings in Chat and Work, and refreshes known model catalogs in the background. Unknown models remain verified before use.

Paid admissions, shared reservations and settlements retain their atomic financial checks. Explicit model and reasoning choices, saved tool results, mission instructions, attachments, approvals and automatic continuation in a new conversation tab are preserved. The complete MGM Work runtime, its 50 plugins, bundled CLIs and third-party licenses are included. These changes do not guarantee a one-second response from every remote model.

Finish active missions and pending approvals before updating. The public Windows application uses the MGM hosted service; a personal local edition has a separate engine and profile. Existing accounts and connections are preserved. Sales and automatic recharges are unchanged.

The installer carries the version-bound MGM update signature. It has no Windows Authenticode certificate. Verify the installer and signature against the attached `SHA256SUMS` and follow [installation instructions](INSTALLATION.md#english).
