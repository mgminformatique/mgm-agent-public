# Faire avancer MGM Agent

Merci de vous intéresser au projet. Une correction de documentation, une
traduction ou un exemple utile constitue déjà une contribution.

## Choisir le bon point de départ

| Vous souhaitez… | Commencez ici |
| :--- | :--- |
| Poser une question ou partager un usage | [Discussions](https://github.com/mgminformatique/mgm-agent-public/discussions) |
| Décrire un problème reproductible | [Formulaire de problème](https://github.com/mgminformatique/mgm-agent-public/issues/new?template=bug_report.yml) |
| Proposer une fonctionnalité | [Formulaire d’idée](https://github.com/mgminformatique/mgm-agent-public/issues/new?template=feature_request.yml) |
| Améliorer les contenus de ce dépôt | Un fork et une pull request, selon les étapes ci-dessous |

## Votre première contribution, depuis GitHub

1. Cliquez sur **Fork** pour créer votre copie de ce dépôt.
2. Dans votre copie, créez une branche pour votre amélioration.
3. Modifiez le fichier concerné : une explication, une traduction, un lien ou
   un exemple d’usage. Une petite proposition ciblée est plus facile à examiner.
4. Relisez l’aperçu et vérifiez les liens que vous avez ajoutés.
5. Ouvrez une **pull request** vers la branche `main` de ce dépôt. Expliquez
   ce qui change et à qui cela sera utile.

Les contributions possibles portent sur les guides, les traductions et la
présentation publique. Le code de l’application est propriétaire et n’est pas
inclus dans ce dépôt. Il n’est donc pas nécessaire de compiler l’application
pour proposer une amélioration ici.

## Quelques idées accessibles

- Clarifier une étape du [guide d’installation](INSTALLATION.md).
- Améliorer le [README anglais](README.md) ou sa [version française](README.fr.md).
- Proposer un nouvel [exemple d’utilisation](EXAMPLES.md) avec un objectif précis.
- Corriger un lien, une faute ou une explication ambiguë.

Les captures et exemples doivent vous appartenir ou être partageables. Retirez
les données personnelles, secrets et informations de clients. Merci de garder
les échanges respectueux, précis et centrés sur le projet.

**Les installateurs sont distribués par MGM dans Releases : n’ajoutez pas d’installateur ni de paquet binaire
dans une pull request.**

## English

Thank you for taking an interest in MGM Agent. Clearer documentation, a better
translation or a useful example all count as contributions.

Use [Discussions](https://github.com/mgminformatique/mgm-agent-public/discussions)
for questions and use cases, and the [issue forms](https://github.com/mgminformatique/mgm-agent-public/issues/new/choose)
for reproducible problems or feature proposals.

To improve this repository:

1. **Fork** it into your GitHub account.
2. Create a branch for one focused improvement.
3. Edit the relevant guide, translation, link or usage example.
4. Review the preview and check your links.
5. Open a **pull request** targeting `main`, explaining the change and who it helps.

This repository contains public materials, not the proprietary application
source code. You do not need to build the application to contribute.
Keep examples free of private data and keep conversations respectful and specific.
**Do not add executables or installation packages to pull requests. MGM distributes official binaries through Releases.**
