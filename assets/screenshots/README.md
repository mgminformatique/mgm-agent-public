# Interface images

These PNG files are unmodified demonstration previews supplied with
MGM Informatique's ShellAmp plugin library:

| File | Tool shown |
| :--- | :--- |
| `shellamp-markdown-studio.png` | Markdown Studio |
| `shellamp-regex-lab.png` | Regex Lab |
| `shellamp-diff-compare.png` | Text Diff |
| `shellamp-task-board.png` | Task Board |

The previews show the French interface with the Cupertino theme and sample
project content. They are not captures of a customer's live mission or
evidence of a particular agent's performance. MGM Work integrates ShellAmp
and also includes the MGM Graphite theme.

No AI image generation or retouching was used on these interface images.
The separate Graphite hero banner is a promotional illustration.
